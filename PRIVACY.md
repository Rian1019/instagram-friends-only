# Privacy

Instagram Friends Only runs locally in the browser.

- It does not collect, transmit, or sell data.
- It does not read or store passwords or Instagram cookies.
- It does not copy or store message contents.
- It uses Chrome local storage only for the Friends-only mode toggle.
- Its Instagram site access is used to hide labeled recommendation elements and redirect Reels/Explore routes.

Authentication remains entirely on `instagram.com`.
